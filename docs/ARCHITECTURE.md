# Gestura.app Architecture

## Status

This document is now a **transition guide**, not the canonical architecture reference.

The canonical architecture documentation is moving into crate-level and module-level Rustdoc so it is generated by `cargo doc` and stays closer to the code it describes.

## Canonical Reference

Use generated docs for architecture and public API reference:

```bash
cargo doc --workspace --no-deps
```

Start with these crate docs:

- `gestura-core` — public facade and workspace integration points
- `gestura-core-foundation` — shared primitives and policies
- `gestura-core-tools` — built-in tools, permissions, and policy
- `gestura-core-pipeline` — pipeline request/response model and persona
- `gestura-core-sessions` — session persistence and workspaces
- `gestura-core-context` — request analysis, context resolution, caching
- `gestura-core-config` — typed configuration and validation
- `gestura-core-security` — secure storage, sandboxing, GDPR helpers
- `gestura-core-streaming` — streaming events, config, cancellation
- `gestura-core-mcp` / `gestura-core-a2a` — protocol domains
- `gestura-core-knowledge` / `gestura-core-memory-bank` — expert knowledge and durable memory
- `gestura-core-agents` / `gestura-core-tasks` — orchestration and task primitives
- `gestura-core-hooks` / `gestura-core-scripting` / `gestura-core-plugins` — extensibility surfaces

## Core Architectural Rules

- **Core-first:** business logic lives in `gestura-core` and `gestura-core-*` domain crates.
- **Thin presentation layers:** `gestura-cli` and `gestura-gui` delegate to core.
- **Stable facade imports:** downstream code should prefer `gestura_core::*` paths unless working directly on a domain crate.
- **Feature-gated integrations:** optional capabilities remain isolated behind Cargo features.

## What Still Belongs in `docs/`

The `docs/` directory should increasingly focus on information that is *not* best represented as Rust API documentation, such as:

- installation and packaging
- build/release workflows
- troubleshooting
- RFCs, assessments, and implementation notes
- user-facing operational guides
