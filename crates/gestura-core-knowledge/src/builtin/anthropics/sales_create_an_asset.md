## Goal
Generate tailored, customer-facing assets (landing page, deck, one-pager, workflow demo) based on:
- prospect context
- audience + concerns
- purpose (what the asset must accomplish)

## Trigger phrases
- “create an asset for [prospect]”
- “make a one-pager / deck / landing page”
- “mock up a workflow demo”

## Two-round question rule
Ask clarifying questions, but cap it at **2 rounds**. If still ambiguous, choose a reasonable default and state it.

## Required clarifying questions
1. **Prospect:** company + deal stage
2. **Audience:** exec / technical / ops / mixed
3. **Goal:** intro, discovery follow-up, technical deep dive, POC proposal, close
4. **Desired action:** what should they do next?
5. **Format:** landing page / deck / one-pager / workflow demo
6. **Tone:** bold & confident / consultative / technical & precise

## Asset build workflow
1. Summarize understanding (asset, audience, goal, must-nail point)
2. Collect missing inputs (limit questions)
3. Research prospect basics (if context is sparse)
4. Map pain points → solution narrative → proof points
5. Generate the asset with a clear CTA
6. Run a quality checklist (no placeholders, consistent names, strong structure)

## Recommended sections by format
### One-pager
- Hero (prospect goal + your value)
- 3 key points (outcomes)
- Proof (metric/quote)
- CTA (next step)

### Deck
- Title + agenda
- “Their priorities” → “How we help” → “Proof” → “Plan” → “Next steps”

### Landing page
- Tabs: Strategic fit | Business impact | Security | Implementation | Next steps

### Workflow demo
- nodes/components + step-by-step walkthrough
- sample payloads (realistic but non-sensitive)

## Quality checklist
- Prospect name spelled correctly
- Clear narrative arc (problem → solution → proof → next step)
- CTA is explicit and timeboxed
- Output matches tone + audience
