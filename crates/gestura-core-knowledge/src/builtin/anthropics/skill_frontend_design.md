## What “good” means
Produce production-grade UI that is intentionally designed (not generic).

## Process
1. Understand context:
   - purpose, audience, constraints
2. Choose a strong aesthetic direction (minimal, brutalist, editorial, etc.)
3. Implement working code with:
   - distinctive typography choices
   - cohesive color system (CSS variables)
   - deliberate spacing + composition
   - purposeful motion/micro-interactions
4. Avoid “AI slop” defaults:
   - overused fonts (Inter/Roboto)
   - predictable purple gradients
   - cookie-cutter layout patterns

## Quality checklist
- Visual hierarchy is clear
- Contrast/accessibility reasonable
- Motion enhances comprehension (not noise)
- No placeholders, cohesive theme
